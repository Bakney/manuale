## Come vengono emesse le ricevute?

Le ricevute vengono emesse automaticamente quando un pagamento viene segnato come pagato.
Se un atleta paga online non è necessario fare nulla. Se invece un atleta paga in contanti
o con mezzi al di fuori della piattaforma, dovrai segnare il pagamento come pagato per emettere
in automatico la ricevuta.

## Come posso scaricare una ricevuta?

Per scaricare una ricevuta, vai nella sezione **Documenti > Ricevute**.
A questo punto, cliccando sull'icona del documento puoi scaricare la ricevuta in formato PDF.

## Come posso inviare una ricevuta?

Per condividere una ricevuta con un atleta, vai nella sezione **Documenti > Ricevute**. A questo
punto, cliccando sull'icona dell'invio ti si aprirà un popup dove potrai:

1. Condividere il link della ricevuta
2. Inviare la ricevuta via email
3. Inviare la ricevuta via WhatsApp

## Eliminare una ricevuta

Se hai abilitato la funzione **Ricevute temporanee eliminabili** dalle impostazioni, puoi eliminare
una ricevuta cliccando sull'icona del cestino fino a 7 giorni dalla sua creazione.
Abilita subito l'impostazione per poter eliminare le ricevute.

## Modifica del progressivo della ricevuta

Per modificare il progressivo di una singola ricevuta, vai nella sezione **Documenti > Ricevute**.
A questo punto cliccando sull'icona della matita puoi modificare il progressivo della ricevuta.

### Configurazioni possibili

Dalle **Impostazioni > Generali** puoi configurare le seguenti opzioni:

1. **Numera Ricevute** - Se abilitata, le ricevute verranno numerate in automatico in base al progressivo
   impostato. Se disabilitata, il progressivo della ricevuta sarà impostato manualmente.
2. **Numero Iniziale Ricevute** - Il numero iniziale del progressivo delle ricevute.
3. **Ricevute temporanee eliminabili** - Se abilitata, le ricevute potranno essere eliminate fino a 7 giorni
   dalla loro creazione. Se disabilitata, le ricevute non potranno essere eliminate.
4. **Data uguale per ricevute e pagamenti** - Se abilitata, la data di emissione della ricevuta sarà uguale
   alla data di pagamento. Se disabilitata, la data di emissione della ricevuta sarà uguale alla data di creazione
   della ricevuta.
