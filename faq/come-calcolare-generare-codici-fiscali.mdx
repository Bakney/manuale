# Calcolo automatico del codice fiscale

Bakney Sport è in grado di **calcolare automaticamente** il codice fiscale di un atleta
a partire dai suoi dati anagrafici. Questo avviene durante la registrazione di un nuovo
socio o tesserato.

## Dati necessari per il calcolo

Per generare il codice fiscale, il sistema ha bisogno di:

- **Nome**
- **Cognome**
- **Sesso** (M o F)
- **Data di nascita**
- **Comune di nascita** (o stato estero)

<Info>
  Tutti i campi sono obbligatori. Se anche uno solo manca o non è valido,
  il sistema non potrà calcolare il codice fiscale.
</Info>

# Come funziona

<Steps>
  <Step title="Compila i dati anagrafici">
    Durante la creazione di un nuovo socio o tesserato, compila tutti i campi
    anagrafici richiesti (nome, cognome, sesso, data di nascita, comune di nascita).
  </Step>
  <Step title="Il codice fiscale viene calcolato">
    Il sistema calcola automaticamente il codice fiscale e lo inserisce nel campo
    corrispondente. Puoi verificarlo prima di proseguire.
  </Step>
</Steps>

# Validazione del codice fiscale

Se un atleta ha già un codice fiscale inserito, il sistema ne **verifica la validità**
controllando che sia conforme al formato italiano. In caso di errori nel carattere
di controllo (CIN), il sistema tenta di correggerlo automaticamente.

# Quando il calcolo automatico potrebbe non funzionare

In alcuni casi il calcolo automatico del codice fiscale potrebbe non essere possibile:

- **Cittadini nati all'estero**: se lo stato estero non è mappato nel sistema
- **Comuni non riconosciuti**: se il nome del comune non corrisponde a quelli presenti
  nell'archivio dei codici catastali
- **Dati incompleti**: se mancano uno o più campi obbligatori

<Tip>
  Se il calcolo automatico non funziona, puoi sempre inserire manualmente il codice
  fiscale nel campo dedicato. Il sistema accetterà qualsiasi codice fiscale valido.
</Tip>

# Inserire o correggere manualmente il codice fiscale

Se hai bisogno di inserire o modificare il codice fiscale di un atleta:

<Steps>
  <Step title="Vai nell'anagrafica dell'atleta">
    Dalla sezione **Libro Soci**, clicca sul nome dell'atleta.
  </Step>
  <Step title="Modifica il codice fiscale">
    Cerca il campo **Codice Fiscale** nei dati anagrafici e inserisci o correggi
    il valore. Salva le modifiche.
  </Step>
</Steps>

<Warning>
  Assicurati che il codice fiscale inserito sia corretto: viene utilizzato per
  l'identificazione univoca dell'atleta e per la generazione di documenti ufficiali.
</Warning>
