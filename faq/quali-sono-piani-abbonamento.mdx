# Piani di abbonamento

Bakney Sport offre tre piani di abbonamento pensati per associazioni di ogni
dimensione: **Base**, **Pro** e **Teams**.

## Confronto tra i piani

| Funzionalità | Base | Pro | Teams |
| --- | :---: | :---: | :---: |
| Anagrafiche illimitate | Si | Si | Si |
| Corsi illimitati | Si | Si | Si |
| Libro soci e tesseramenti | Si | Si | Si |
| Pagamenti e ricevute | Si | Si | Si |
| Comunicazioni di base | Si | Si | Si |
| Moduli di iscrizione personalizzati | Si | Si | Si |
| Presenze automatiche | - | Si | Si |
| Report avanzati | - | Si | Si |
| Pagamenti online con Stripe | - | Si | Si |
| Comunicazioni avanzate (automazioni) | - | Si | Si |
| Collaboratori con permessi | - | Si | Si |
| Accesso multi-utente | - | - | Si |

## Piano Base

Il piano Base include tutte le funzionalità fondamentali per gestire la tua
associazione sportiva:

- Gestione anagrafiche, soci e tesserati
- Creazione e gestione di corsi
- Registrazione pagamenti e generazione ricevute
- Comunicazioni di base (email)
- Moduli di iscrizione con QR code e link condivisibile

<Info>
  Il piano Base non ha limiti sul numero di anagrafiche o corsi che puoi creare.
</Info>

## Piano Pro

Il piano Pro include tutto il piano Base, con l'aggiunta di funzionalità avanzate:

- **Presenze automatiche**: gli atleti vengono segnati automaticamente come presenti
  nel giorno della lezione
- **Report avanzati**: statistiche dettagliate sull'andamento dell'associazione
- **Pagamenti online con Stripe**: ricevi pagamenti con carta di credito, debito,
  Apple Pay, Google Pay e addebito SEPA
- **Comunicazioni avanzate**: automazioni e workflow per l'invio automatico di email
- **Collaboratori**: invita altre persone a gestire l'associazione con permessi personalizzati

## Piano Teams

Il piano Teams include tutto il piano Pro ed è pensato per associazioni più
strutturate che hanno bisogno di un accesso multi-utente completo.

## Come cambiare piano

Per passare a un piano superiore:

<Steps>
  <Step title="Vai nelle impostazioni di fatturazione">
    Dalla barra laterale clicca sul tuo **Profilo** e poi su **Abbonamento**.
  </Step>
  <Step title="Scegli il piano">
    Seleziona il piano che preferisci tra le opzioni disponibili.
  </Step>
  <Step title="Completa il pagamento">
    Segui le istruzioni per completare il pagamento. Puoi scegliere tra
    abbonamento **mensile** o **annuale**.
  </Step>
</Steps>

<Tip>
  L'abbonamento annuale ti permette di risparmiare rispetto al pagamento mensile.
</Tip>
