# Esportare il Libro Soci

Per esportare l'elenco dei tuoi soci e tesserati:

1. Vai nella sezione **Associazione > Libro Soci e Tesserati**
2. Se necessario, applica i **filtri** desiderati (ad esempio per stato dell'iscrizione, tag, periodo)
3. Clicca sull'icona di **esportazione** (generalmente rappresentata da una freccia verso il basso o un'icona di download)
4. Verrà generato un file **Excel (.xlsx)** con tutti i dati degli atleti attualmente visualizzati

Il file esportato include informazioni come:
- Nome e cognome
- Codice fiscale
- Data di nascita
- Contatti (email, telefono)
- Stato dell'iscrizione
- Data di iscrizione e scadenza
- Tag assegnati

<Tip>
    Applica i filtri **prima** di esportare per ottenere solo i dati che ti servono. Ad esempio, puoi filtrare solo gli atleti con iscrizione attiva oppure quelli con un determinato tag.
</Tip>

# Esportare i pagamenti

Per esportare i dati relativi ai pagamenti:

1. Vai nella sezione **Contabilità > Pagamenti**
2. Utilizza i filtri disponibili per selezionare il periodo, lo stato del pagamento (pagato/non pagato) o la tipologia
3. Clicca sull'icona di **esportazione**
4. Verrà generato un file **Excel (.xlsx)** con l'elenco dei pagamenti

Il report dei pagamenti include:
- Nome dell'atleta
- Importo
- Data di creazione e data di pagamento
- Stato (pagato o non pagato)
- Descrizione e causale
- Metodo di pagamento

<Info>
    Filtrare per periodo è molto utile per generare report mensili o annuali da presentare in sede di bilancio.
</Info>

# Esportare il registro presenze

Per esportare i dati delle presenze:

1. Vai nella sezione **Registro Presenze** del corso che ti interessa
2. Seleziona il **periodo** da esportare
3. Clicca sull'icona di **esportazione**
4. Verrà generato un file **Excel (.xlsx)** con le presenze registrate

Il file esportato include:
- Nome dell'atleta
- Date delle lezioni
- Stato di presenza per ogni lezione
- Eventuali note

# Esportare tutti i dati dell'associazione

Bakney offre anche la possibilità di effettuare un'**esportazione completa** di tutti i dati della tua associazione. Questa funzione crea un archivio ZIP contenente tutti i dati in formato strutturato.

Per effettuare l'esportazione completa:

1. Vai in **Impostazioni > Archivio**
2. Clicca su **Esporta tutti i dati**
3. Il sistema genererà un file ZIP contenente tutti i dati dell'associazione

L'esportazione completa include:
- Dati anagrafici di tutti i soci e tesserati
- Iscrizioni e tesseramenti
- Corsi e iscrizioni ai corsi
- Pagamenti e ricevute
- Certificati medici
- Carnet e presenze
- Comunicazioni e workflow
- Documenti e allegati

<Warning>
    L'esportazione completa può richiedere diversi minuti a seconda della quantità di dati. Una volta completata, il file sarà disponibile nell'archivio dei documenti.
</Warning>

<Note>
    Le esportazioni complete vengono conservate per un massimo di **30 giorni** e viene mantenuto un massimo di **3 esportazioni** per associazione. Le esportazioni più vecchie vengono eliminate automaticamente.
</Note>

# Formati disponibili e consigli

## Formato dei file

Il formato principale di esportazione è **Excel (.xlsx)**, compatibile con:
- Microsoft Excel
- Google Fogli (Google Sheets)
- LibreOffice Calc
- Numbers (Mac)

## Consigli per l'esportazione

- **Filtra prima, esporta dopo**: applica sempre i filtri necessari prima di esportare per ottenere un file più ordinato e contenente solo i dati che ti servono
- **Esportazioni periodiche**: effettua esportazioni regolari (ad esempio mensili) dei pagamenti per avere sempre un backup aggiornato
- **Esportazione completa annuale**: a fine stagione sportiva, effettua un'esportazione completa come archivio storico della tua associazione
- **Verifica i dati**: dopo l'esportazione, apri il file per verificare che contenga tutti i dati attesi

<Tip>
    Se hai bisogno di condividere i dati con il tuo commercialista o con il consiglio direttivo, l'esportazione in Excel è il modo più pratico per farlo.
</Tip>
